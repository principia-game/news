Hello, Principia 2026.08.16 has been released. This is a big update that brings a lot of new changes to the game on desktop platforms, replacing all the game's dialogs that were previously implemented using GTK with new ones using Dear Imgui.

As usual, you can find downloads on the **[Download](/download)** page, and the full list of changes in [the Changelog](/wiki/Changelog). F-Droid and various Linux distribution packages should receive the update within due time.

## New Dear Imgui dialogs
On desktop, all of the game's dialogs that were previously implemented using GTK have been completely rewritten using Dear Imgui instead. This UI toolkit offers various improvements over GTK such as being more lightweight and better integrated in the game window. These new dialogs have also already served as the ones used in the web version, as well as more niche ports of the game like the Windows XP and Nintendo Switch ports.

<figure>
	<img src="/news/images/33/imgui_robot_dialog.webp" style="width:600px" alt="Screenshot of the new robot dialog using Dear Imgui.">
</figure>

This is something that has been in the works for a long time to free the game from its dependency on GTK3, and it's the result of a lot of work to rewrite all the dialogs. [Principia 2026.07.09](/news/30) saw the first introduction of dialogs implemented using Dear Imgui in a stable release, primarily replacing the popup menus whose previous GTK implementations had issues across platforms. After that release I worked hard the subsequent weeks to reimplement all the rest of the dialogs and bring them up to parity with the old ones. The [Are we Imgui yet?](https://principia-web.se/imgui) page is now all green and will stay that way as the transition is now complete.

[I made a post on the forums](https://principia-web.se/forum/thread?id=88) last month asking the community to help test the new dialogs, and put a banner across the community site to give attention to this forum thread. I'm not sure how many people actually tested the new dialogs, but I assume from the relative silence that there are no major issues remaining with them. Yes, they do look and feel different from the old GTK dialogs, but in general I feel they are an improvement over the old ones in every regard after having tested and used them for a while.

For Android, the game still uses the native dialogs on that platform. It would be nice to also replace those as they have a lot of issues with parity over the desktop dialogs, and having only one set of dialogs for all platforms would be rather beneficial since nobody is interested in updating the Android dialogs. But I am not sure of the usability of the Dear Imgui dialogs on phones, so this is still something that needs to be investigated further.

But with this, the game no longer depends on GTK3 where it previously did. The installed footprint of the Windows version is now about 25MB smaller and Principia on Linux will now run on Wayland by default if available, no longer crashing on GNOME. Linux distributions packaging Principia can remove the dependency on GTK3.

## Sticky Note improvements
The [Sticky notes](https://principia-web.se/wiki/Sticky_Note) have seen some improvements in this update. Most noticeable is that they use a new font which in my opinion is more readable. The spacing of the text has also been improved and the amount of lines of text you can put on a single sticky note has been increased, allowing you to put more text than before.

## Haiku OS fixes
It turned out that the experimental port of Principia to Haiku OS has been broken for quite some time, both due to a change back in December that used something that wasn't available on Haiku, and due to some compatibility issues with Haiku and Dear Imgui. This has now been fixed and you can run Principia on Haiku OS again, new Dear Imgui dialogs included.

</figure>

## Minor main menu improvements
There are some minor improvements to the main menu which you are likely to notice when updating. The play and create buttons have been redesigned to look like the rest of the buttons in the main menu, and the logo has been centered. Minor things.

<figure>
	<img src="/news/images/33/main_menu.webp" alt="Screenshot of the new changes in the main menu">
</figure>

After having worked a lot with Dear Imgui, coming back to Principia's own homegrown widget system (used for the menu and other simple GUI stuff) feels very archaic. I would quite like to revamp the rest of the game's GUI in some way, potentially using components from Dear Imgui, but don't have any concrete plans for that yet.

## Rendering pipeline improvements
Even though this isn't a visible change for this update, it's worth mentioning that the rendering and postprocessing pipeline has been improved in the background. While this probably won't affect anything for this release, it will allow for gamma correction and bloom to function across all platforms, including those using OpenGL ES. In addition to this the game will have a cleaner postprocessing pipeline allowing for more graphical effects to be added to the game in the future!
