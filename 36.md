Hello, Principia 2026.10.22 has been released. This is a security release primarily to update the CA store bundled on Android to remove certificates related to compromised eMudhra intermediate certificates. The update also contains hardening of the featured level parser, including buffer overflow vulnerability fixes.

As usual, you can find downloads on the **[Download](/download)** page, and the full list of changes in [the Changelog](/wiki/Changelog). F-Droid and various Linux distribution packages should receive the update within due time.

## Note about the 21th October downtime
Yesterday the Principia community site was down for about 6 hours until 14:00 GMT. This was to safeguard the server from two high severity remote code execution vulnerabilities in PHP that could have compromised the server. The patches were intended to be released by the PHP team at 14:00 GMT, but information about the vulnerabilities was independently discovered before that point and exploitation began to happen to websites in the wild. By the time I had woken up, I read about this news and pulled the server offline to keep it safe.

I remain confident that there was no compromise of the server in the time before I woke up and pulled the site offline, and I have since applied the patches that were released by the PHP team. The community site has been operating normally ever since then.

## Android: CA store update, eMudhra
On the 20th of October, it was made public that several intermediate certificates issued by the company eMudhra were compromised, making it possible to issue fraudulent certificates for any domain. As a result, all software which bundles its own CA store has been pushing out updates to remove the root certificates tied to the intermediate certificates as a response.

For the Android version, we bundle a CA store for verifying network connections to the community site over HTTPS. All other platforms should use the system CA store, which is updated by your operating system vendor and should not be affected if you remain up to date. Modern browsers should have already been patched, but you can read more about the incident and test your browser at https://emudhra.we-have-a-problem.com/

## Buffer overflow vulnerability in the featured level parser
A buffer overflow vulnerability was discovered in the featured level parser. Essentially, if the title or author of a featured level is too long, it writes to a buffer which is too small and causes memory corruption. This typically just leads to a crash when it tries writing over memory it should not be, but theoretically could be exploited to execute arbitrary code on systems with little to no memory protection.

I would like to thank [Grace / Noxii](https://github.com/noxii7d) for discovering the issue and responsibly disclosing it. I was unsure whether to classify this as a bug or as a vulnerability, but given that the featured level file is fetched from the community site, this could theoretically be exploited over the network if you were to point your client to a malicious third party community site. The official Principia community site is not affected by this issue however, as it limits the size of featured level metadata well before it reaches your client.

Outside of this, the parser has also been further hardened against malformed or maliciously crafted files with ridiculously large numbers, gracefully erroring out in more instances instead of crashing or running out of memory.
