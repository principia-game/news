Hello, Principia 2026.07.15 has been released. This is a minor patch release that fixes some issues with the previous release from last week, in addition to other minor fixes that have been made since then and are included in this release.

As usual, you can find downloads on the **[Download](/download)** page, and the full list of changes in [the Changelog](/wiki/Changelog). F-Droid and various Linux distribution packages should receive the update within due time.

While the changes in this release are not much to write about, I would like to mention some upcoming stuff that have been in the works since the last release, slated for release sometime later into the future.

## Are we Imgui yet?
The progress of replacing all GTK dialogs in the game with Dear Imgui has been coming along quite well since the last release. As of writing, about 75% of all dialogs have been implemented.

A page has been made to track the current progress as a nice coloured bar, with the current status of each dialog in the game: [principia-web.se/imgui](https://principia-web.se/imgui)

If you want to test the new dialogs to make sure that they work as expected this would be highly appreciated. See the [Nightly Builds](https://principia-web.se/wiki/Nightly_Builds) page on the Wiki, which contains all the latest changes that happen with the game!

## Web version
As mentioned in the previous news article, one of the things that the new Dear Imgui-based dialogs allows us to do is get the game onto new and interesting platforms where GTK is not available. One such platform is the Web, where we have had an experimental port of Principia where you can play levels straight from the community site, right in your web browser.

But why stop there? As the amount of implemented Dear Imgui-based dialogs have increased, the usability of the sandbox in the web has gradually increased alongside to the point where fleshing out other parts of the web version have become worthwhile.

<figure>
	<img src="/news/images/31/upload_dialog_web.webp" style="width:650px" alt="Principia running in the web browser, my username is visible in the top-left corner and the Imgui level publish dialog is visible.">
	<figcaption>Hey... Why don't I implement being able to upload levels now?</figcaption>
</figure>

Yesterday I continued the work on reimplementing the game's networking for the web. You will be able to log in on the community site, launch the web version of Principia (where you will be automatically logged in), open the sandbox, build and publish levels. All in your web browser, without needing to install anything.

The first ever level uploaded from the web is [available here](https://principia-web.se/level/1663). With the current state of my work, publishing a level works, but the game will immediately freeze after that point. It's promising, but not quite there yet. You should hopefully see it appearing sometime soon when all the glaring issues have been resolved.
